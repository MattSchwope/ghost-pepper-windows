# Product Brief

## Name

Working name: **Ghost Pepper Windows**

## Problem

Windows users need a private, local-first way to dictate text, clean it, paste it into any app, and preserve useful notes without sending audio/transcripts to a cloud service.

## Target user

A technical recruiter, operator, consultant, or knowledge worker who:
- takes many calls
- writes many notes
- wants local-first privacy
- wants searchable Markdown
- wants low API cost
- wants a voice-to-workflow system, not just transcription

## Primary use cases

1. Dictate a LinkedIn message.
2. Dictate an email response.
3. Dictate candidate notes.
4. Transcribe a candidate screen.
5. Summarize a client intake call.
6. Create structured Markdown notes for Obsidian/RAG.
7. Later: capture meeting audio and produce summaries/action items.

## MVP

The MVP is a voice keyboard.

```text
hotkey → record → transcribe → clean → paste → save Markdown
```

## Out of scope for MVP

- diarization
- system audio recording
- GUI settings
- installer
- signed executable
- cloud sync
- mobile app
- multi-user support
- advanced RAG
